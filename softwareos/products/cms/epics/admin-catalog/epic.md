# Admin Catalog CMS

> Product: ../../mission.md
> Status: in-progress
> Created: 2026-10-19 · Roles planned: PM, Tech

## Summary

Stride admins manage the catalog themselves at `/admin`, inside the existing Stride site: products, categories, stock and product images. Their changes show up in the storefront without a developer or a deploy. Only users with the admin role can reach the CMS, and the API enforces it. This epic delivers the whole CMS Phase 1 MVP.
